# Утилиты

Маленькие страницы-инструменты, работают прямо в браузере.

- [Telegram: ID чатов и тем](https://nikola-chesn.github.io/tools/telegram-ids.html) — по токену бота находит ID групп, тем, каналов и личных чатов. Токен уходит только на api.telegram.org и нигде не сохраняется.
- [Живые огоньки](https://nikola-chesn.github.io/tools/candle-glow/) — WebGL-эффект «живого» света свечей для фото и компонент [`candle-glow.js`](candle-glow/) для своих сайтов. Фото обрабатываются только в браузере.
