# Утилиты

Небольшие страницы-инструменты, которые работают прямо в браузере, без сервера и установки.

**Сайт:** https://nikola-chesn.github.io/tools/

| Утилита | Что делает |
|---|---|
| [Telegram: ID чатов и тем](https://nikola-chesn.github.io/tools/telegram-ids/) | По токену бота находит ID групп, тем, каналов и личных чатов и отправляет тестовое сообщение. Токен уходит только на `api.telegram.org` и нигде не сохраняется. |
| [Живые огоньки](https://nikola-chesn.github.io/tools/candle-glow/) | WebGL-эффект «живого» света свечей для фото: огоньки мерцают и светятся, воздух над пламенем дрожит. Есть демо (PNG, видео, готовый код) и компонент [`candle-glow.js`](candle-glow/) для своих сайтов. Фото обрабатываются только в браузере. |


1. Создать папку `имя-утилиты/` с `index.html` и `README.md`. На странице сделать ссылку «← Все утилиты» на `../`.
2. Добавить карточку в `index.html` и строку в таблицу выше.
3. После `git push` в `main` GitHub Pages обновит сайт примерно за минуту.
