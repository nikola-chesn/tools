# DepthParallax — объёмное фото по карте глубины

WebGL-эффект: фото и его карта глубины превращаются в «окно» в сцену. Когда ведёшь мышью, ближние предметы остаются на месте, а фон плавно уходит в противоположную сторону. Можно добавить мягкий свет свечей из [CandleGlow](../candle-glow/): мерцание, ореол, дрожание воздуха. Один файл, без зависимостей.

- Демо: https://nikola-chesn.github.io/tools/depth-parallax/ — загрузите фото и карту глубины, настройте, сохраните кадр, видео или готовый код.
- Компонент: [`depth-parallax.js`](depth-parallax.js).

## Быстрый старт

```html
<canvas id="scene" style="display:block;width:100%;height:100vh"></canvas>

<script src="depth-parallax.js"></script>
<script>
  new DepthParallax(document.getElementById('scene'), {
    src: 'img/photo.jpg',
    depth: 'img/photo-depth.png', // светлое — близко, тёмное — далеко
  });
</script>
```

Карта глубины — чёрно-белая картинка того же кадра и тех же пропорций. Её можно сделать нейросетью (Depth Anything, Marigold, генераторы карт глубины в Photoshop/Canva и т. п.). Если в карте наоборот (тёмное — близко), добавьте `invert: true`.

## Опции

| Опция | По умолчанию | Что делает |
|---|---|---|
| `src`, `depth` | — | Фото и карта глубины: URL, `<img>`, `<canvas>`, `File`/`Blob` |
| `invert` | `false` | Карта наоборот: тёмное — близко |
| `strength` | `0.05` | Сила объёма: насколько далеко уходит фон (доля ширины фото) |
| `focus` | `1` | Что стоит на месте: `1` — самое близкое, `0` — самое далёкое, `0.5` — середина |
| `vertical` | `0.6` | Движение по вертикали относительно горизонтали |
| `smooth` | `4` | Сглаживание карты в пикселях (убирает рваные края) |
| `ease` | `0.06` | Насколько плавно камера догоняет мышь (меньше — мягче) |
| `idleSway` | `0.35` | Сцена сама медленно покачивается через 3 с без движения мыши (0 — выкл.) |
| `sway`, `swayPeriod` | `0`, `6` | Постоянное покачивание вместо мыши (для видео), период в секундах |
| `pointer` | `'window'` | `'window'` — мышь по всей странице; `'element'` — только над холстом |
| `focusPoint`, `fit`, `zoom` | `[0.5, 0.5]`, `'cover'`, `1` | Кадрирование как у `object-position` / `object-fit`; запас по краям добавляется сам |
| `flames` | `[]` | Огоньки `[[x, y, размер], …]` в долях фото — как в CandleGlow |
| `glow`, `scale`, `flicker`, `heat` | `1`, `1`, `1`, `0.6` | Свечение, размер, мерцание огоньков, дрожание воздуха |
| `dark`, `vignette`, `grain`, `warm` | `0.12`, `0.6`, `0.5`, `0.5` | Затемнение, тёмные края, зерно, тёплый тон |
| `showDepth` | `false` | Показать карту глубины вместо фото (для проверки) |
| `pixelRatio`, `size` | `1.5`, `null` | Качество рендера; точный размер `[w, h]` для сохранения |
| `motion` | `'auto'` | `'auto'` уважает «уменьшить движение» в системе |
| `onReady`, `onError` | — | Колбэки |

Без WebGL на холсте просто показывается фото.

## Методы

```js
const fx = new DepthParallax(canvas, options);
fx.set({ strength: 0.08, focus: 0.5 });      // поменять настройки на лету
fx.setImage('b.jpg', 'b-depth.png');         // другое фото и карта (Promise)
fx.setDepth('b-depth-v2.png');               // только карта
fx.setFlames([[0.5, 0.48, 0.02]]);           // огоньки
fx.snapshot();  fx.restart();                // кадр как data URL; покачивание с начала
fx.pause();  fx.play();  fx.destroy();
```

Огоньки можно найти автоматически функцией `CandleGlow.detect` из `candle-glow.js`.

## Как это работает

Для каждого пикселя на экране шейдер ищет, какой пиксель фото должен сюда попасть после сдвига. Сдвиг зависит от глубины: `сдвиг = движение мыши × сила × (focus − глубина)`. Ближнее (глубина ≈ focus) не двигается, дальнее сдвигается сильнее и в обратную сторону. Глубина в точке, откуда берётся пиксель, сама зависит от сдвига, поэтому точка уточняется за 10 шагов: так края предметов не «размазываются», а ближний объект честно перекрывает фон.

Карта глубины заранее слегка размывается (`smooth`), чтобы на границах не было ступенек, а картинка чуть увеличивается, чтобы при самом сильном сдвиге не было видно краёв. Огоньки двигаются вместе со своим слоем глубины, а дрожание воздуха над пламенем применяется до параллакса — одинаково к фото и к карте глубины, поэтому фитиль и пламя колышутся вместе со своей глубиной.
