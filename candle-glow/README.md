# CandleGlow — живые огоньки на фото

WebGL-эффект для фотографии со свечами или гирляндой: пламя мерцает и светится, воздух над ним дрожит, вся сцена чуть «дышит» светом и плавно следует за мышью. Один файл, без зависимостей и сборки.

- Демо: https://nikola-chesn.github.io/tools/candle-glow/ — загрузите свои фото, поправьте огоньки, скачайте кадр PNG, видео или готовый код.
- Файл компонента: [`candle-glow.js`](candle-glow.js) (~20 КБ, ~7 КБ в gzip).
- Изначально сделан для первого экрана сайта Sparkling Lights.

## Быстрый старт

```html
<canvas id="candles" style="display:block;width:100%;height:100vh"></canvas>

<script src="https://nikola-chesn.github.io/tools/candle-glow/candle-glow.js"></script>
<script>
  new CandleGlow(document.getElementById('candles'), {
    src: 'img/photo.jpg',
    flames: [[0.28, 0.40, 0.026], [0.48, 0.24, 0.026]], // или 'auto'
  });
</script>
```

Лучше скопировать `candle-glow.js` к себе в проект, а не грузить с github.io.

Холст может быть любого размера: фото заполняет его как `background-size: cover` (точка фокуса — опция `focus`).

## Огоньки

Каждый огонёк — `[x, y, размер]`:
- `x`, `y` — положение пламени от 0 до 1 (0,0 — левый верхний угол фото);
- `размер` — радиус свечения в долях высоты фото, обычно `0.015–0.035` (чайная свеча на широком фото ≈ `0.026`).

До 32 огоньков на фото. Проще всего расставить их в демо (кнопка «Показать и править огоньки») и скопировать готовый код.

`flames: 'auto'` — компонент сам найдёт огоньки (маленькие яркие точки, заметно светлее своего окружения). Обычно находит пламя свечей и лампочки гирлянды; лучше проверить и поправить в демо.

## Опции

| Опция | По умолчанию | Что делает |
|---|---|---|
| `src` | — | Фото: URL, `<img>`, `<canvas>`, `File`/`Blob` |
| `flames` | `[]` | Огоньки или `'auto'` |
| `focus` | `[0.5, 0.5]` | Какая часть фото остаётся видна при обрезке (как `object-position`) |
| `fit` | `'cover'` | `'cover'` — заполнить и обрезать; `'contain'` — показать фото целиком |
| `dark` | `0.22` | Затемнение фото, чтобы огоньки сильнее выделялись (0–1) |
| `glow` | `1` | Сила свечения вокруг пламени |
| `scale` | `1` | Множитель размера всех огоньков |
| `flicker` | `1` | Мерцание пламени и общего света |
| `heat` | `1` | Дрожание горячего воздуха над пламенем |
| `vignette` | `1` | Тёмные края |
| `warm` | `1` | Тёплая цветокоррекция |
| `grain` | `1` | Плёночное зерно |
| `parallax` | `1` | Движение за мышью (0 — выкл.) |
| `zoom` | `0.965` | Небольшое увеличение, чтобы при параллаксе не было видно края |
| `pixelRatio` | `1.5` | Максимальная плотность пикселей (выше — чётче, но тяжелее) |
| `size` | `null` | Точный размер рендера `[ширина, высота]` (например, для сохранения кадра) |
| `motion` | `'auto'` | `'auto'` уважает «уменьшить движение» в системе; `true`/`false` — принудительно |
| `autoDetect` | `{}` | Настройки поиска для `'auto'`: `{ sensitivity: 0.4, max: 24, size: 1 }` |
| `onReady`, `onError` | — | Колбэки: фото загружено / WebGL недоступен или фото не загрузилось |

Если WebGL недоступен, на холсте просто показывается фото (как фон).

## Методы

```js
const fx = new CandleGlow(canvas, options);

fx.set({ dark: 0.4, glow: 1.5 });          // поменять настройки на лету
fx.setImage('other.jpg', 'auto');          // другое фото (Promise)
fx.setFlames([[0.5, 0.3, 0.02]]);          // другие огоньки
fx.toImage(x, y);   fx.fromImage(u, v);    // пиксели холста ↔ координаты фото
fx.snapshot('image/jpeg', 0.92);           // текущий кадр как data URL
fx.pause();  fx.play();  fx.destroy();     // destroy освобождает WebGL-контекст

CandleGlow.detect('photo.jpg', { sensitivity: 0.5 }).then(flames => …);
```

Автозапуск по атрибутам:

```html
<canvas data-candle-glow data-src="photo.jpg" data-flames="auto" data-dark="0.3"
        style="width:100%;height:80vh"></canvas>
<script src="candle-glow.js"></script>
<script>CandleGlow.auto();</script>
```

## Как это работает

Всё рисует один фрагментный шейдер на весь холст, каждый кадр:

1. **Фото как текстура.** Шейдер берёт пиксель фото, обрезает его как `cover` и чуть сдвигает вслед за мышью — отсюда лёгкий параллакс.
2. **Дрожание воздуха.** Для каждого огонька считается «зона влияния» — вытянутый вверх овал вокруг пламени и столб над ним. В этой зоне координаты, по которым читается фото, смещаются шумом, который меняется со временем. Пламя на самом фото начинает колыхаться, а воздух над ним — плыть, как от жара. Сами пиксели не рисуются заново, просто читаются чуть со стороны.
3. **Свечение.** Поверх фото добавляются два мягких пятна света (широкий оранжевый ореол и маленькое яркое ядро). Яркость каждого огонька «дышит» на своём шуме, поэтому они мерцают вразнобой, как настоящие свечи.
4. **Атмосфера.** Фото слегка затемняется и утепляется, края уходят в темноту (виньетка), общий свет едва заметно пульсирует, сверху ложится плёночное зерно. На тёмном фоне свечение смотрится особенно живо.

Автопоиск огоньков работает без шейдера: фото уменьшается до 480 px, для каждой точки считается, насколько она ярче своего окружения, и выбираются самые яркие почти белые точки (пламя горит почти белым, а светлый воск или стена — ровные, без пика).
