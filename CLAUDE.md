# Tools — мои утилиты

Набор маленьких страниц-инструментов, которые работают прямо в браузере (без сервера и сборки).

- Папка: `~/Documents/Cloude/Tools`
- GitHub: https://github.com/nikola-chesn/tools — **публичный** репозиторий, ветка `main`
- Сайт: https://nikola-chesn.github.io/tools/ — GitHub Pages, обновляется сам примерно за минуту после `git push` в `main`

## Что здесь есть

Каждая утилита — своя папка с `index.html` и `README.md`; адрес `https://nikola-chesn.github.io/tools/<папка>/`.

| Файл / папка | Что делает |
|---|---|
| `index.html` | Главная страница со списком утилит (карточки). Каждую новую утилиту добавляй сюда. |
| `telegram-ids/` | **Telegram: ID чатов и тем.** По токену бота вызывает `getMe` и `getUpdates` и находит группы, темы в группах (форумы), каналы и личные чаты. По кнопке «Выбрать» показывает `chat_id` и `message_thread_id`, копирует их, собирает строки для `.env` и отправляет тестовое сообщение (`sendMessage`). Если у бота включён webhook (ошибка 409), предлагает его отключить. |
| `candle-glow/` | **Живые огоньки.** Компонент `candle-glow.js` (WebGL-шейдер «живого» света свечей для фото, без зависимостей, глобальный `CandleGlow`), демо `index.html` (загрузка нескольких фото, автопоиск и ручная правка огоньков, ползунки, PNG/видео, генерация кода) и `README.md` с API. |
| `depth-parallax/` | **Объёмное фото.** Компонент `depth-parallax.js` (глобальный `DepthParallax`): фото + карта глубины (светлое = близко), параллакс за мышью, плюс упрощённый свет свечей из CandleGlow. Демо `index.html` (несколько фото, ИИ-карта глубины через `depth-ai.js` или своя, ползунки, PNG, видео 12 с, код) подключает `../candle-glow/candle-glow.js` только для автопоиска огоньков. |
| `telegram-ids.html` | Заглушка-редирект со старого адреса на `telegram-ids/` (ссылки на старый адрес уже разошлись — не удалять). |
| `README.md` | Описание репозитория: таблица утилит, структура, как добавить новую. |

### Подробности про telegram-ids/
- Токен вводится в поле `type=password`, никуда не сохраняется (ни localStorage, ни cookies) и отправляется только на `https://api.telegram.org` (Telegram API разрешает запросы из браузера, CORS `*`).
- Боты в группах видят только команды, поэтому в инструкции на странице просим отправить `/id` в нужной группе или теме. Telegram хранит необработанные обновления около суток.
- Название темы берётся из `reply_to_message.forum_topic_created.name`; если его нет — «Тема N».
- Тип чата: группа / канал / личный чат (`chat.type`).
- Проверено: настоящий Telegram отвечает с опубликованной страницы; разбор групп, тем, каналов и личных чатов проверен на подставных ответах.
- Важно при тестах: не подменяй `window.fetch` на вкладке, которую может увидеть пользователь, — он однажды ввёл туда настоящий токен и увидел тестовые данные.

### Подробности про candle-glow/
- Исходник — шейдер первого экрана сайта Sparkling Lights (`Сайт/js/main.js`, `HEROES`), вынесен в универсальный компонент: до 32 огоньков, все параметры — опции, автопоиск огоньков `CandleGlow.detect`.
- Автопоиск: фото 480 px, «насколько точка ярче локального среднего» × яркость⁶, подавление соседей. На фото с сайта находит все 7 свечей (+ огни гирлянды на фоне).
- В inline-скрипте демо нельзя писать `</script>` внутри строк — только `<\/script>` (иначе страница ломается).
- Проверка локально: `python3 -m http.server 8810` в папке Tools → http://localhost:8810/candle-glow/ (с `file://` фото через выбор файла тоже работают).

### Подробности про depth-parallax/
- Сдвиг: `O × (focus − depth)`, точка в фото уточняется 10 итерациями (`p = mix(p, uv + O*(fc - dep(p)), .6)`), чтобы ближнее перекрывало фон без размазывания. Запас по краям — автоматический зум в `_zoom()`.
- Дрожание воздуха `d` прибавляется к uv ДО параллакса (`ud = uv + d`), чтобы фото и карта глубины колыхались вместе (просьба пользователя: иначе фитиль на фото двигается, а на карте нет).
- `depth-ai.js` (глобальный `DepthAI`): карта глубины нейросетью в браузере — Transformers.js 4.3.2 с jsDelivr (динамический `import()`), модель `onnx-community/depth-anything-v2-small`; WebGPU+fp16 (~50 МБ), иначе WASM+q8 (~27 МБ). Проверено: на Mac WebGPU, первая карта ~5 с с загрузкой, дальше ~0,5 с; результат почти совпадает с картой пользователя. Выход нормализуется min/max, светлое = близко.
- Демо: несколько фото (миниатюры со статусом карты), очередь генерации (текущее фото первым), своя карта сопоставляется с фото по имени (`ball.webp` + `ball-depth.webp`) или по «серости»; для ИИ-карт галочка «наоборот» игнорируется. Видео — 12 с (два цикла покачивания по 6 с, без шва).
- При открытии демо сразу показывает пример: `example.jpg` (фото с первого экрана Sparkling Lights, выложено по просьбе пользователя) + заранее созданная ИИ-карта `example-depth.jpg` (836×470), чтобы посетителю не качать модель. Пример работает только по http(s), с `file://` WebGL не возьмёт картинку — тогда просто пустое окно.
- Вверху блок «01 Глубина из одного фото / 02 Живой свет свечей / 03 Где применять».
- Карта глубины размывается на CPU (3 прохода box blur, до 1024 px) и грузится как LUMINANCE-текстура.
- Опции освещения те же, что у CandleGlow, но по умолчанию мягче (dark .12, vignette .6, grain .5, warm .5, heat .6).
- Тест: в браузере pane реальная мышь пользователя перебивает подставные `pointermove`; для проверки снимай слушатель `__fx._onMove` и задавай `__fx._tm` напрямую, потом верни.

## Правила для утилит
- Своя папка на утилиту: `index.html` (стили и скрипт внутри) + `README.md`; компонент для других проектов — отдельный `.js` рядом (как `candle-glow/`). Без сборки и без внешних библиотек, если можно обойтись. На странице ссылка «← Все утилиты» на `../`.
- Работает с `file://` и с GitHub Pages одинаково.
- Интерфейс на русском. Оформление по умолчанию как у `telegram-ids/`: карточки с радиусом 16px, синий `#3977D5`, тёмно-синий текст `#1B3459`, светлый фон `#F5F8FD`, поддержка тёмной темы через `prefers-color-scheme`, без теней.
- Исключение по оформлению: `candle-glow/` и `depth-parallax/` — в стиле сайта Sparkling Lights (кремовый `#f3ece2`, шоколадный `#2a1f1a`, золотой `#e8b45a`/`#9a6a1f`, шрифты Cormorant + Jost), по просьбе пользователя.
- Никаких секретов в репозитории: он публичный. Ключи и токены пользователь вводит на странице сам.
- Новая утилита → добавить карточку в `index.html` и строку в таблицу `README.md`.

## Публикация
- Правки делаем локально и проверяем (открыть файл в браузере или во встроенном предпросмотре).
- `git push` в `main` (= публикация на сайт) — только когда пользователь скажет «заливай» / «заливай в прод».
- Новые ветки — только по просьбе пользователя.
- Коммиты от `nikola-chesn` (в настройках git этого репозитория уже стоит его noreply-почта).
- После публикации проверь, что страница открывается по ссылке (GitHub Pages обновляется 30–60 секунд).
