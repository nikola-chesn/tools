# Telegram: ID чатов и тем

Страница: https://nikola-chesn.github.io/tools/telegram-ids/

Помогает узнать, куда бот может писать: ID группы, канала, темы в группе-форуме или личного чата.

## Как пользоваться

1. Нет бота — создайте его у [@BotFather](https://t.me/BotFather) командой `/newbot`, он пришлёт токен.
2. **Группа:** добавьте бота и отправьте там `/id` (если включены темы — в каждой нужной теме). **Канал:** сделайте бота администратором и опубликуйте любое сообщение. **Личный чат:** нажмите у бота «Старт».
3. Вставьте токен на странице и нажмите «Найти чаты и темы».
4. Нажмите «Выбрать» у нужного чата: страница покажет `chat_id` и `message_thread_id`, соберёт строки для `.env` и может отправить тестовое сообщение.

## Что внутри

- Один файл `index.html`, без библиотек.
- Использует методы Telegram Bot API `getMe`, `getUpdates` и `sendMessage`. Если у бота включён webhook (ошибка 409), предлагает его отключить (`deleteWebhook`).
- Токен вводится в поле-пароль, никуда не сохраняется и отправляется только на `https://api.telegram.org`.
- Telegram хранит необработанные сообщения около суток: если чат не находится, напишите в нём `/id` ещё раз.
